# Light, spacious landing page refresh

## Direction
- Shift the landing page from the current dark treatment to a light, airy GuardFlow-inspired presentation with generous vertical spacing and a strong editorial rhythm.
- Keep BookedSecure's existing logo, copy, sections, links, and signed-in Dashboard behaviour.
- Replace the blue accent system with the previous purple/pink family, used as a restrained secondary accent rather than a dominant full-page colour.

## Page changes
- Remove the complete live enquiry preview from the opening section.
- Rebalance the opening section around the main message, action, and supporting line with more breathing room.
- Restyle the outcome strip, feature explanation, four-step process, audience list, closing action, and footer for the lighter theme.
- Preserve the existing 12-column structure while allowing wider whitespace between major content groups.

## Theme details
- Add a light landing background, white surfaces, dark ink text, muted slate copy, quiet borders, and soft shadows.
- Add semantic purple/pink accent tokens for highlighted words, links, icons, and secondary emphasis.
- Keep actions accessible and high-contrast, with the main action visually stronger than the purple/pink accents.

## Verification
- Check desktop and phone layouts for spacing, text fit, overflow, links, and signed-out behaviour.
- Confirm the removed enquiry content no longer appears and the page has no runtime or build errors.
